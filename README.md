# Aplicando el lenguaje de marcado HTML

Entrada de blog portafolio desarrollada para la **Unidad 2 – Saber 2: Aplicando el lenguaje de marcado para creación de páginas web y transferencia de información**, del curso **Herramientas de Programación III**.

La página presenta un resumen (máximo 250 palabras) sobre la importancia de utilizar herramientas de desarrollo como **Bootstrap** en la creación de páginas HTML.

**Ver la página:** https://valen-17.github.io/MiPortafolio_Valentina_Perez_HTML/

## Tecnologías utilizadas

| Tecnología | Uso en el proyecto |
|---|---|
| **HTML5** | Estructura semántica de la página (`nav`, `header`, `main`, `section`, `article`, `footer`). |
| **CSS3** | Estilos propios: degradados, franjas del encabezado, tarjetas flotantes, animaciones y efectos al pasar el mouse. |
| **JavaScript** | Contador automático de palabras del resumen, barra de progreso de lectura, menú que cambia al hacer scroll y aparición animada de las secciones. |
| **Bootstrap 5.3** | Sistema de rejilla (grid) responsive, barra de navegación, insignias (badges), botones, utilidades de espaciado y Bootstrap Icons. |

## Estructura del proyecto

```
├── index.html        Página principal
├── css/
│   └── estilos.css   Estilos propios que complementan a Bootstrap
├── js/
│   └── main.js       Interactividad de la página
└── entrada-blog.md   Texto de la entrada del blog
```

## Secciones de la página

1. **Portada:** título de la entrada y tarjetas que ilustran el grid, un ejemplo de código y los componentes de Bootstrap.
2. **Entrada del blog:** resumen sobre la importancia de Bootstrap, con autora, fecha y contador de palabras.
3. **¿Por qué usar Bootstrap?:** tarjetas con los beneficios principales del framework.

La página es *responsive*: se adapta a computadores, tabletas y celulares.

## Cómo ejecutarla

No requiere instalación. Basta con descargar o clonar el repositorio y abrir `index.html` en el navegador:

```bash
git clone https://github.com/Valen-17/MiPortafolio_Valentina_Perez_HTML.git
```
